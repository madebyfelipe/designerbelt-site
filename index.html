THE SMALL PRINT, SIMPLIFIED

A few things
to know.

Is it available yet?+

Not yet. Designer's Belt is in development. Release details will be announced here.

Is this a subscription?+

The app will be sold as a one-time license: $5 for up to 3 devices. Optional Cloud will be billed separately as a subscription, with its price to be announced. See pricing.

Does it work offline?+

Yes. The local tools don't need internet. Cloud features need a connection.

Are my files uploaded?+

Local tools process your files on your PC. Cloud uploads are optional.

Which platforms is it built for?+

Designer's Belt is being built for Windows. Final system requirements will be published before release.

What's still on the roadmap?+

OpticAlign and FixedLink are in development. Features and release scope may change before launch.
